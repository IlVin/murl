# Организация шарда на PostgreSQL

Каждый шард хранится в отдельной DATABASE а не в SCHEMA потому, что DATABASE можно размещать на указанном TABLESPACE,
который в свою очередь можно размещать на указанном диске.
Таким образом шардирование будет работать даже на одном инстансе БД.

В древние времена я таким образом шардировал сервис Открытки@Mail.Ru: у меня было 4 инстанса и на каждом по десятку жестких дисков.
В предпраздничные дни бутылочным горлышком была пропускная способность сети 100 Mbit (гигабит в те времена только появился и был очень дорог).
