# Internal — Внутренняя логика приложения

Директория `internal` содержит все компоненты приложения, скрытые от внешнего импорта. Проект спроектирован по принципам **Clean Architecture**, что обеспечивает независимость бизнес-логики от внешних инструментов и баз данных.

## Структура слоев

### 1. Доменный слой (Domain & Models)
Сердце приложения, не имеющее внешних зависимостей.
*   `internal/domain`: Базовые сущности (например, `Notification`).
*   `internal/model`: Системные алгоритмы шардирования, механика коротких ссылок и управление JWT-сессиями.

### 2. Прикладной слой (Service)
Оркестрация бизнес-процессов.
*   `internal/service`: Реализация сценариев использования (Use Cases). Здесь происходит валидация URL, координация работы с репозиторием и отправка событий в аудит.

### 3. Слой передачи данных (DTO)
*   `internal/dto`: Объекты для обмена данными между API и внутренними слоями. Реализуют событийную модель через интерфейс `EventType`.

### 4. Инфраструктурный слой (Adapters)
Реализация взаимодействия с внешним миром.
*   `internal/adapters/pgc`: Продвинутый драйвер PostgreSQL с поддержкой **CQRS**, батчинга и телеметрии.
*   `internal/adapters/audit`: Адаптеры для записи аудита в файлы и отправки по HTTP.

### 5. Слой хранения (Repository)
Абстракция над данными.
*   `internal/repository`: Интерфейсы хранилищ.
*   `internal/repository/repo`: Универсальный фасад с поддержкой драйверов **InMemory** и **PgDB**.
*   `internal/repository/wal`: Журнал опережающей записи для обеспечения сохранности данных в памяти.

### 6. Конфигурация
*   `internal/config`: Иммутабельный конфигуратор, поддерживающий флаги и переменные окружения.

## Ключевые механизмы

*   **Event Sourcing**: Приложение может восстанавливать состояние `InMemory` репозитория, проигрывая события из `WAL`.
*   **Observability**: Сквозная интеграция с **OpenTelemetry** (трейсы и метрики) через все слои — от HTTP до драйверов БД.
*   **Graceful Shutdown**: Гарантированная обработка накопленных буферов (аудит, батчи БД) при завершении работы.

## Тестирование

Каждый пакет снабжен:
