## Конфигурация (Module: config)

Модуль управления конфигурацией спроектирован как **иммутабельный объект** с поддержкой нескольких источников данных, строгой типизацией и встроенной валидацией.

### Ключевые особенности

*   **Иммутабельность (Immutable State):** Объект конфигурации защищен от случайных изменений в рантайме. Любая модификация (через методы `Set...`) возвращает новую копию объекта. Это исключает возникновение побочных эффектов и "гонок данных" (data races).
*   **Приоритетность настроек:** Система автоматически разрешает конфликты параметров, следуя иерархии (от низшего к высшему):
    1.  Значения по умолчанию (Hardcoded defaults).
    2.  Флаги командной строки (Command line flags).
    3.  Переменные окружения (Environment variables).
*   **Строгая типизация и валидация:**
    *   `SocketAddr`: Гарантирует корректность сетевого адреса `host:port` с использованием `net.SplitHostPort`.
    *   `ShortBaseURL`: Обеспечивает валидность базового URL, автоматически очищая его от чувствительных данных (User Info) для безопасности.
    *   **Fail-Fast Validation:** При инициализации путей к файлам (Event Storage, Audit File) модуль проверяет доступность файлов на запись/чтение.
*   **Поддержка аудита:** Встроенные параметры `AuditFile` и `AuditURL` позволяют гибко настраивать логирование действий системы как в локальные файлы, так и на внешние сервисы.
*   **Тестируемость:** Архитектура `NewConfig` позволяет подменять системные функции чтения переменных окружения, что обеспечивает **100% покрытие Unit-тестами** без зависимости от глобального окружения ОС.

### Параметры конфигурации


| Флаг | Переменная окружения | Описание | Дефолт |
| :--- | :--- | :--- | :--- |
| `-a` | `SERVER_ADDRESS` | Адрес запуска HTTP-сервера | `localhost:8080` |
| `-b` | `BASE_URL` | Базовый адрес сокращенных URL | `http://localhost:8080/` |
| `-d` | `DATABASE_DSN` | Строка подключения к БД (PostgreSQL) | `""` |
| `-f` | `FILE_STORAGE_PATH` | Путь к файлу хранилища событий | `""` |
| `--audit-file` | `AUDIT_FILE` | Путь к файлу логирования аудита | `""` |
| `--audit-url` | `AUDIT_URL` | URL внешнего сервиса аудита | `nil` |

### Использование

Модуль поддерживает удобные цепочки вызовов (chaining) и внедрение зависимостей для тестов:

```go
// 1. Стандартная инициализация в main.go
args := os.Args[1:]
cfg, err := config.NewConfig(&args, os.LookupEnv)
if err != nil {
    log.Fatal("Failed to load config:", err)
}

// 2. Создание модифицированной копии (например, для интеграционных тестов)
u, _ := url.Parse("https://internal.local")
testCfg := cfg.SetRepoDrv("InMemory").
               SetAuditURL(u).
               SetJWTTTL(time.Hour)

// 3. Использование типизированных параметров
fmt.Printf("Server starting on: %s\n", cfg.ListenAddr())
```

### Тестирование

Для запуска тестов с проверкой покрытия используйте:
```bash
go test -v -cover ./internal/config/...
```
