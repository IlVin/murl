## Транспортный уровень (Module: handlers)

Модуль `handlers` отвечает за обработку HTTP-трафика, маршрутизацию запросов и мониторинг. Реализован с использованием паттерна **Dependency Injection**, что позволяет полностью изолировать логику обработки запросов от сетевого интерфейса.

### Ключевые особенности

*   **Динамическая маршрутизация (Router Factory):** Система поддерживает переключение между движками маршрутизации через конфигурацию. Это позволяет выбирать между стандартной библиотекой и внешними фреймворками без изменения кода хендлеров:
    *   **Standard `http.ServeMux`**: Использование современных паттернов маршрутизации Go 1.22+.
    *   **`chi.Router`**: Поддержка продвинутого роутинга через популярную библиотеку `go-chi`.
*   **Middleware логирование (Observability):** Реализован механизм перехвата данных каждого запроса. Благодаря кастомному врапперу `ResponseWriter`, система логирует не только входящие параметры, но и итоговый **HTTP Status Code**, а также **время обработки** запроса.
*   **Безопасность ресурсов:** Строгое управление жизненным циклом тела запроса (`io.ReadAll` с гарантированным `Close`) предотвращает утечки памяти и дескрипторов под высокой нагрузкой.
*   **Абстракция над сервисом:** Хендлеры взаимодействуют с бизнес-логикой через интерфейс `MicroURLService`, что обеспечивает легкость тестирования (100% покрытие Unit-тестами с использованием моков).

    Service --> Handler
    Handler --> Wrap[Capture Status Code]
