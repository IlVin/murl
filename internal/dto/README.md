# DTO (Data Transfer Objects) — Слой обмена данными и событий

Пакет `internal/dto` определяет структуры данных, используемые для передачи информации между слоями приложения (API, Business Logic, Storage) и для фиксации событий в системе аудита.

## Событийная модель (EvType)

Центральной частью пакета является перечисление `EvType`, которое позволяет типизировать любые действия в системе.

*   **Идентификация**: Каждое ключевое DTO реализует метод `EventType() EvType`.
*   **Генерация**: Строковые представления типов событий генерируются автоматически инструментом `stringer`.
*   **Назначение**: Используется для восстановления состояния из `Event Storage` и фильтрации данных в системе аналитики.

## Основные группы DTO

### 1. Операции с единичными ссылками
*   `AddURL` / `AddURLBySessionID`: Данные для создания коротких ссылок (анонимно или с привязкой к пользователю).
*   `GetURL` / `GetURLBySessionID`: Информация для редиректа, включая флаг `IsGone` для обработки удаленных ссылок.
*   `DeleteURLBySessionID`: Запрос на массовое удаление ссылок владельцем.

### 2. Пакетные операции (Batching)
*   `BatchItem`: Базовый элемент группового запроса с поддержкой `CorrelationID`.
*   `Batch` / `BatchBySessionID`: Контейнеры для массовой обработки ссылок.

### 3. Системные уведомления
*   `AuditlogNotification`: Специализированная структура для внешней системы аудита, содержащая временные метки (`ts`) и детали действий пользователей.

## Принципы проектирования

1.  **Независимость от БД**: Теги `json` определяют формат внешнего API, а методы `EventType` позволяют сохранять объекты в плоские логи событий.
2.  **Плоская структура**: DTO минимизируют использование сложной логики, отдавая предпочтение примитивным типам и UUID.
3.  **Информативность**: Флаги вроде `ConflictFlag` или `IsGone` позволяют прокидывать статус операции из репозитория до HTTP-хендлера без анализа текстовых ошибок.

## Использование

```go
import "murl/internal/dto"

// Пример создания события для лога
event := dto.AddURL{
    OriginalURL: "https://example.com",
    ShortURL:    "shrt",
}

// Тип события для маршрутизации
msgType := event.EventType() // dto.EvAddURL
```

---
```Документация:``` Полный список констант `EvType` и полей структур доступен через `godoc -http=:6060` в разделе `internal/dto`.
