# Module: Postgres Cluster (pgc)

`PgCluster` — оркестратор пула инстансов PostgreSQL. Реализует логику шардирования данных на уровне репозитория, обеспечивая единый интерфейс доступа к распределенной базе данных.

---

## Возможности

*   **Консистентное шардирование**: Использование `model.ShardID` гарантирует одинаковое распределение ключей между In-Memory и Postgres слоями.
*   **Масштабируемость**: Архитектура поддерживает маппинг множества логических шардов на ограниченное количество физических инстансов.
*   **Безопасный Lifecycle**: Атомарное управление миграциями, проверкой доступности (Ping) и корректным завершением работы всех узлов.

---

## Использование

```go
cfg := &ClusterConfig{size: 64, dsn: "postgres://..."}
m, _ := metrics.NewPgMetrics(reg)

cluster, err := pgc.NewPgCluster(ctx, cfg, m)
if err != nil {
    log.Fatal(err)
}

// Запуск миграций (выполнится 1 раз для каждого уникального инстанса)
if err := cluster.RunMigrations(ctx); err != nil {
    log.Fatal(err)
}
```

---

## Технические детали

*   **GetShard**: Выполняет O(1) поиск нужного инстанса по ID шарда.
*   **Error Handling**: При сбоях инициализации кластер автоматически закрывает уже открытые пулы соединений через `Close()`.
*   **Logging**: Интегрировано структурированное логирование (`slog`) для отслеживания этапов инициализации и миграций.
