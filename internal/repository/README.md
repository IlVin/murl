# Repository Layer — Абстракция хранилищ

Пакет `internal/repository` определяет контракты для сохранения и извлечения данных. Архитектура поддерживает **Polyglot Persistence**: приложение может работать как с классической реляционной БД (PostgreSQL), так и с высокопроизводительным шардированным хранилищем в памяти (InMemory).

## Архитектура интерфейсов

Слой разделен на специализированные интерфейсы для обеспечения принципа разделения ответственности (Interface Segregation):

1.  **Repo**: Основной интерфейс приложения. Объединяет CRUD-операции и методы жизненного цикла (`Ping`, `Close`). Содержит метод `On` для реализации **Event Sourcing** (восстановление состояния из логов).
2.  **RepoLinks**: Низкоуровневые операции со ссылками (анонимные сокращения, пакетная обработка).
3.  **RepoLinksBySessionID**: Операции, привязанные к пользователю (личный кабинет, удаление своих ссылок, история).

## Реализации хранилищ

### 1. InMemory (internal/repository/inmem)
Высокопроизводительное хранилище для работы с данными "в лету".
*   **Шардирование**: Данные распределяются по независимым сегментам для минимизации блокировок (`lock contention`).
*   **False Sharing Protection**: Использование выравнивания кэш-линий процессора для максимальной скорости на многоядерных системах.
*   **Event Sourcing**: При использовании `EventStoragePath`, состояние памяти может быть полностью восстановлено после перезагрузки.

### 2. PostgreSQL (в разработке)
Адаптер для работы с постоянным хранилищем.
*   Использует продвинутые возможности пакета `pgc` (CQRS, Batching).
*   Обеспечивает транзакционность и долговечность данных.

## Конфигурирование

Репозиторий инициализируется на основе драйвера, указанного в конфиге (`RepoDrv`):
*   `InMemory`: Быстрый старт, данные в ОЗУ.
*   `PgDB`: Работа с внешней базой данных PostgreSQL.

## Использование в приложении

```go
// Пример использования в бизнес-логике
func (s *Service) Process(ctx context.Context, data dto.AddURL) {
    // Репозиторий скрывает детали реализации (БД или Память)
    res, err := s.repo.AddURL(ctx, data)
    // ...
}
```
