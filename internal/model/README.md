## Модель сокращения ссылок (Module: model)

Модуль `model` отвечает за низкоуровневую логику формирования и парсинга коротких идентификаторов URL. Основная цель модуля — создание максимально коротких, безопасных для веб-среды и детерминированных ссылок.

### Визуальная структура короткого URL

```text
    https://murl.sh / . F zkS
    |_____________|   | | |__|
           |          | |  |
        Base URL      | |  +-- Index (Base64 от Varint)
                      | +-- Shard Symbol (1 символ)
                      +-- Signature
```

### Алгоритм кодирования

Для достижения минимальной длины идентификатора используется комбинация двух эффективных техник:

1.  **Variable-length quantity (Varint):** Индекс записи из базы данных (`uint64`) кодируется с использованием алгоритма `binary.Uvarint`. Это позволяет малым числам занимать всего 1 байт, постепенно увеличиваясь только при росте базы данных.
2.  **Base64 URL-Safe (No Padding):** Полученный бинарный массив преобразуется в строку с использованием алфавита `ABC...-_`. Мы используем вариант без знаков дополнения (`=`), что делает ссылки чистыми и пригодными для использования в любых частях URL без дополнительного экранирования.

### Структура короткого пути

Сгенерированный путь (Path) имеет следующую структуру:
`/{Signature}{ShardSymbol}{EncodedIndex}`

*   **Signature (1 символ):** Первый символ после слэша '.' сигнализирует, что путь относится к классу коротких ссылок
*   **ShardSymbol (1 символ):** Первый символ после слэша определяет номер шарда (сегмента базы данных). Мы используем собственный словарь из 64 символов, что позволяет адресовать до 64 независимых хранилищ.
*   **EncodedIndex (динамическая длина):** Остальная часть пути — это компактно упакованный индекс записи. Для первых записей в каждом шарде общая длина пути составит всего **3 символа** (включая слэш).

### Особенности реализации

*   **Безопасность (Panic-free):** Все функции парсинга снабжены проверками границ (bounds checking), что исключает возможность падения приложения при получении некорректных или слишком коротких ссылок.
*   **Иммутабельность:** При генерации ссылок модуль работает с копиями объектов `url.URL`, предотвращая случайное изменение глобальных настроек базового адреса.
*   **Производительность:** Использование стандартных библиотек `encoding/binary` и `encoding/base64` гарантирует минимальные затраты CPU и практически нулевые аллокации памяти в "горячих" точках.

### Примеры преобразования
| ShardID | Index | Base URL | Result URL |
|:---:|:---:|:---:|:---:|
| 0 | 0 | `http://localhost:8080` | `http://localhost:8080/.AAA` |
| 5 | 12345 | `https://murl.sh` | `https://murl.sh/.FzkS` |
| 63 | 1 | `https://murl.sh` | `https://murl.sh/._AQ` |
