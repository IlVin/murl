# Model Layer — Доменные модели и системные алгоритмы

Пакет `internal/model` содержит ключевые структуры данных и алгоритмы, определяющие внутреннюю логику работы приложения `murl`. Это "мозг" системы, где сосредоточены правила формирования ссылок и распределения нагрузки.

## Ключевые компоненты

### 1. Формат коротких путей (Short Paths)
Вместо случайных строк мы используем компактную бинарную упаковку. Короткий путь состоит из трех частей:
*   `/.` — статический маркер (префикс).
*   `ShardID` — один символ из словаря Base64, указывающий на номер узла.
*   `Index` — порядковый номер записи, закодированный через `Uvarint` и Base64.

**Преимущества:**
*   **Экстремальная краткость**: Первые 128 ссылок на каждом шарде будут состоять всего из 3-х символов после слэша.
*   **Быстрый парсинг**: Для определения шарда не нужно обращаться к БД.

### 2. Универсальное шардирование (ShardID)
Для горизонтального масштабирования реализована система распределения ключей по шардам на основе хеш-функции `xxHash`.

*   **Типобезопасность**: Благодаря Generics поддерживаются строки, целые числа и объекты, реализующие интерфейсы `fmt.Stringer` или `Hashable`.
*   **Производительность**: Для целочисленных типов реализован путь без аллокаций в куче.
*   **Равномерность**: Алгоритм минимизирует диспропорцию данных между узлами кластера.

### 3. Управление сессиями (Session)
Структура `Session` связывает `UUID` пользователя с временем жизни его авторизации (`TTL`). Используется совместно с `jwtmanager` для аутентификации запросов.

## Описание модулей

*   `model.go` — Алгоритмы шардирования, парсинг путей, работа с контекстом сессий.
*   `jwtmanager/` — Генерация и валидация токенов безопасности.
*   `auditlog/` — Асинхронный диспетчер уведомлений (Observer).
*   `event/` — Универсальный конверт для событий системы.

## Примеры использования

### Генерация короткого пути
```go
// Шард №5, индекс записи 12345
path, err := model.MakeShortPath(5, 12345)
// Результат: /.F09O (примерно)
```

### Определение шарда для пользователя
```go
// Распределяем пользователя по 64 шардам на основе его ID
shard := model.ShardID(userUUID, 64)
```
