# JWT Manager — Управление сессиями и безопасностью

Пакет `internal/model/jwtmanager` обеспечивает полный цикл работы с JSON Web Tokens (JWT): от генерации и подписи до валидации и контроля времени жизни (TTL) сессий.

## Основные функции

1.  **Генерация токенов (HS256)**: Создание компактных и безопасных токенов, содержащих `SessionID` пользователя.
2.  **Валидация и парсинг**: Проверка подлинности подписи и срока действия (Expiration Time).
3.  **Управление TTL**: Логика автоматического продления сессий (Session Refresh).
4.  **Безопасность**: Защита от атак с подменой алгоритма подписи (`alg: none`).

## Алгоритм работы с сессиями

Менеджер реализует стратегию "мягкого" обновления токенов:
*   При каждом создании токена время его жизни устанавливается на стандартную величину `JWTTTL`.
*   Метод `NeedRemaining` позволяет определить, когда сессия приближается к завершению (осталось менее 25% времени). Это сигнал для приложения, что нужно выдать пользователю новый токен, не дожидаясь разлогина.

## Интерфейсы и конфигурация

Менеджер не зависит от конкретной структуры конфига, а использует интерфейс `JWTManagerConfig`, что упрощает тестирование и интеграцию.

```go
type JWTManagerConfig interface {
    JWTSecretKey() string
    JWTTTL() time.Duration
}
```

## Примеры использования

### Инициализация
```go
// jwtSecretKey и jwtTTL берутся из общего конфига приложения
manager, err := jwtmanager.NewJWT(cfg)
```

### Создание и проверка токена
```go
// Генерируем токен для новой или существующей сессии
token, err := manager.GenerateJWT(session)

// Проверяем токен из HTTP заголовка
session, err := manager.VerifyJWT(tokenString)
if err != nil {
    // Токен невалиден или просрочен
}
```

### Проверка необходимости обновления
```go
if manager.NeedRemaining(session) {
    // Генерируем новый токен и отправляем в ответе (например, в Set-Cookie)
    newToken, _ := manager.GenerateJWT(session)
}
```
