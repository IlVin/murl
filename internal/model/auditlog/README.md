# Auditlog — Система асинхронного аудита и нотификаций

Пакет `internal/model/auditlog` реализует ядро системы распределения уведомлений. Он служит связующим звеном между бизнес-логикой приложения и различными адаптерами вывода (инфраструктурой).

## Архитектура

Система построена на базе паттерна **Observer** (Наблюдатель) и использует модель **Worker Pool** для асинхронной обработки событий.

### Основные компоненты:

1.  **Auditlog**: Центральный диспетчер, который принимает уведомления и распределяет их по подписчикам.
2.  **Subscriber**: Интерфейс для потребителей данных (адаптеров). Любой компонент, реализующий `Update` и `GetID`, может стать подписчиком.
3.  **Очередь событий**: Внутренний буферизированный канал (`NotificationBufSize = 1000`), который сглаживает пиковые нагрузки.

## Особенности реализации

*   **Асинхронность**: Метод `Notify` мгновенно возвращает управление, помещая задачу в буфер. Это исключает задержки в основном бизнес-цикле из-за медленной записи в файлы или сетевых запросов.
*   **Безопасность конкурентного доступа**: Регистрация и удаление подписчиков защищены `sync.RWMutex`, что позволяет динамически изменять состав потребителей во время работы.
*   **Graceful Shutdown**: Метод `Stop()` закрывает входной канал и дожидается (`sync.WaitGroup`), пока все запущенные воркеры не обработают остатки очереди. Это гарантирует доставку важных данных аудита при выключении приложения.
*   **Изоляция ошибок**: Сбой одного подписчика (например, таймаут HTTP) не влияет на работу других и не останавливает процесс рассылки.

## Использование

### Настройка и запуск
```go
// 1. Создаем диспетчер
logManager := auditlog.NewAuditlog()

// 2. Регистрируем адаптеры
logManager.Register(fileAuditor)
logManager.Register(urlAuditor)

// 3. Запускаем пул воркеров (например, 5 потоков)
logManager.Start(5)
defer logManager.Stop()
```

### Отправка уведомления из бизнес-логики
```go
func (s *Service) CreateOrder(ctx context.Context) {
    // ... логика создания ...

    notif := domain.Notification{Message: []byte("order created")}
    _ = s.audit.Notify(ctx, notif)
}
```
