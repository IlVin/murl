# Event Model — Универсальный конверт событий

Пакет `internal/model/event` предоставляет механизмы для создания, сериализации и связывания событий. Он является основой для реализации систем Event Sourcing, аудита и распределенных логов.

## Основная концепция

Каждое действие в системе упаковывается в **Event** — неизменяемый объект, который содержит:
1.  **ID**: Уникальный UUID события.
2.  **Type**: Тип события (из `dto.EvType`), позволяющий понять, что внутри.
3.  **Payload**: Полезная нагрузка (DTO в формате JSON).
4.  **Causality (Parents)**: Список ID всех событий, которые привели к возникновению текущего.

## Ключевые возможности

### 1. Строгая типизация через Generics
Использование дженериков в функциях `MakeEvent` и `GetPayload` гарантирует, что вы не сможете упаковать в событие случайный объект или ошибиться типом при извлечении данных. Ограничение `Payload` включает только разрешенные DTO.

### 2. Цепочки событий (Traceability)
Благодаря сохранению списка `ParentID`, система позволяет восстановить всю цепочку причинно-следственных связей. Например, можно отследить, какой именно запрос на создание ссылки привел к конкретному событию перехода спустя месяц.

### 3. Иммутабельность
Реализация `baseEvent` защищена от изменений. Методы получения данных (например, `GetParents`) возвращают копии данных, гарантируя, что состояние события не будет случайно изменено в процессе обработки.

## Использование

### Создание события
```go
// Упаковываем DTO в конверт
ev, err := event.MakeEvent(dto.AddURL{OriginalURL: "https://google.com"}, nil)
if err != nil {
    return err
}

// Создаем дочернее событие, передав родителя
childEv, _ := event.MakeEvent(dto.GetURL{ShortURL: "abc"}, ev)
```

### Извлечение данных
```go
// Типобезопасное извлечение
payload, err := event.GetPayload[dto.AddURL](ev)
if err != nil {
    // Тип не совпал или ошибка парсинга
}
fmt.Println(payload.OriginalURL)
```

### Сериализация для хранения
```go
// Превращаем в JSON для записи в файл или БД
data, _ := ev.Serialize()

// Восстанавливаем из байтов
restoredEv, _ := event.Parse(data)
```

## Расширение системы
Для добавления нового типа события необходимо:
1. Добавить константу в `internal/dto/evtype.go`.
2. Описать структуру DTO и реализовать метод `EventType()`.
3. Добавить тип в ограничение интерфейса `Payload` в `event.go`.

```Документация:``` Полный интерфейс доступен через `godoc -http=:6060` в разделе `internal/model/event`.
